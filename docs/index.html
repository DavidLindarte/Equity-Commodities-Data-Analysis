Energy stock & news monitor: Woodside and Shell

Single-company news, such as an offshore outage, an accident, a community strike or a CEO statement, can move one stock without moving the market. This monitor tracks that idiosyncratic risk. It follows the share prices of Woodside (WDS) and Shell (SHEL) alongside the volume of Google News articles on the topics that can move them, and raises an alert when either jumps.

How to read this page

1 · Price vs its own average

Each stock is compared with its average closing price since the monitoring start date. Far above or below the average means the market has re-priced the company.

2 · News volume as a signal

For each topic, the monitor counts Google News articles published since the start date. A sudden rise in the count is a news spike: something is happening before it shows up in prices.

3 · Alerts

An alert fires when a stock moves at least 2% between two checks, or when a topic gains 5 or more articles. Locally the alerts are spoken aloud; here they are listed below.

    How it works

    1. Original tool, run locally: main.py runs every 15 seconds. It calls stocks.py (Yahoo Finance prices vs their average since a start date you choose) and monitor.py (Google News RSS article counts for each topic). It speaks alerts with macOS text-to-speech and appends every check to a CSV that feeds a Power BI dashboard.
    2. This hosted version: GitHub Actions runs the same checks every 3 hours on weekdays (pipeline/snapshot.py). It reuses monitor.py, appends to data/history.csv with the same columns as the Power BI CSV, and refreshes this page.
    3. Fully configurable: you can change the tickers, the topics, the start date and the alert thresholds. It needs no paid API keys.
    pip install -r requirements.txt
python main.py          # local real-time monitor with voice alerts (macOS)
python pipeline/snapshot.py   # one hosted-style snapshot → data/history.csv + docs/data/latest.json
    Data: Yahoo Finance (prices) and Google News RSS (article counts). Educational project, not investment advice.
